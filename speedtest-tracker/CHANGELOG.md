# Changelog

All notable changes to this add-on are documented in this file.

## [1.0.0] - 2024-06-04

### Added

- Initial release of Speedtest Tracker add-on for Home Assistant
- Support for amd64, aarch64, and armv7 architectures
- Web interface accessible on port 8000
- Configurable app port, key length, and log level
- Health check monitoring
- Data persistence in `/config/speedtest-tracker/`
- Automatic restart on failure
- Full integration with Home Assistant add-on system

### Features

- Monitor internet speed performance (download, upload, ping)
- Schedule automated speed tests
- View historical performance data
- Receive notifications on performance issues
- Multi-language support

---

For detailed information about Speedtest Tracker, see the [official documentation](https://docs.speedtest-tracker.dev/).
